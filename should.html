💡 Should / Shouldn't

dare consigli — dovresti e non dovresti

💡 La regola

Should si usa per dare consigli o fare raccomandazioni. Non è un obbligo — è un suggerimento gentile!

✅ should

dovresti — consiglio positivo
You should rest.
She should see a doctor.

❌ shouldn't

non dovresti — consiglio negativo
You shouldn't eat that.
He shouldn't be rude.
soggetto + should + verbo base
soggetto + shouldn't + verbo base
SoggettoAffermativoNegativo
I / You / He / She / We / They should go shouldn't go
🎨 Trucco: should non cambia mai! Stessa forma per tutti i soggetti — niente -s per he/she/it. Molto più semplice di have to!

⚖️ Should vs Must — la differenza

must = DEVI farlo — è un obbligo forte
You must wear a seatbelt. (è la legge!)
should = DOVRESTI farlo — è un consiglio
You should sleep more. (sarebbe meglio!)
💬 Situazioni tipiche per should:
• Consigli di salute: "You should drink more water."
• Raccomandazioni: "You should try this pizza!"
• Opinioni: "I think she should apologize."
• Chiedere consiglio: "Should I call him?"

❓ Come fare le domande
