📍 There is / There are

per dire che qualcosa c'è in un luogo

💡 A cosa serve?

Si usa per dire che qualcosa c'è o ci sono in un posto. La scelta dipende se la cosa è una sola o più di una.

1️⃣There is (there's)
una cosa sola
There is a book.
🔢There are
più cose (plurale)
There are three books.
🎨 In italiano: There is = "c'è" · There are = "ci sono".

✅ Singolare e plurale

Quante cose?FormaEsempio 🔊
1 cosa There is
(There's)		 There is a cat.
tante cose There are There are five cats.
💡 Guarda la cosa DOPO: se è singolare → There is. Se è plurale (finisce in -s, o c'è un numero più grande di 1) → There are.

❌ Forma negativa

FormaEsempioAscolta
There isn't
(there is not)		 There isn't a dog.
There aren't
(there are not)		 There aren't any chairs.
⚠️ isn't per una cosa sola · aren't per più cose. Nelle frasi negative al plurale spesso si usa any (= nessuno/alcuni).

❓ Forma interrogativa

DomandaRisposta breve 🔊
Is there...?
Is there a pen? 		Yes, there is. / No, there isn't.
Are there...?
Are there any pens? 		Yes, there are. / No, there aren't.
💡 Per fare la domanda, basta mettere is o are prima di "there": There is → Is there?
