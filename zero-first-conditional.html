🔀 Zero e First Conditional

le frasi con if — sempre vero o futuro possibile?

💡 Due frasi con "if"

Una frase con if (se) ha due parti: la condizione (if...) e il risultato. Cambia tutto a seconda che sia una verità di sempre o un'ipotesi sul futuro.

0️⃣ Zero Conditional

sempre vero 🔁
fatti, scienza, regole
If you heat ice, it melts.

1️⃣ First Conditional

futuro possibile 🔮
ipotesi reale, previsione
If it rains, I'll stay home.
🎨 Trucco: se è una cosa che succede sempre 🔁 → Zero. Se parli di un futuro che potrebbe succedere 🔮 → First.

0️⃣ Zero Conditional — verità sempre vere

If + presente ,  presente
Frase🔊
If you heat ice, it melts.
If you don't water plants, they die.
If you mix blue and yellow, you get green.
💡 Si usa per fatti, leggi scientifiche e abitudini sempre vere. Qui if vuol dire "ogni volta che" (whenever). Tutti e due i verbi al presente.

1️⃣ First Conditional — futuro possibile

If + presente ,  will + verbo base
Frase🔊
If it rains tomorrow, I'll stay home.
If you study, you'll pass the exam.
If we hurry, we'll catch the bus.
💡 Si usa per il futuro reale e probabile: previsioni, promesse, avvertimenti. La condizione (if...) resta al presente, il risultato va con will.

⚠️ Le 3 regole d'oro

RegolaEsempio
Dopo if mai will!✓ If it rains…   ✗ If it will rain…
if può stare prima o dopoIf it rains, I'll stay. = I'll stay if it rains.
Virgola solo se if è all'inizioIf…, …  ·  … if … (niente virgola)
🧲 Errore classico: If you will study, you will pass. → giusto: If you study, you will pass.
